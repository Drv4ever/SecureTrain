---
id: authority_03
tactic: authority
title: Senior Engineering and Architecture Audits
source: MITRE ATT&CK T1078 / T1566
technique: Hierarchical Technical Directives
---
Phishing lures impersonating the VP of Engineering or Chief Architect instruct developers to submit active session tokens, API keys, or IAM configurations for an emergency security audit. Because technical leaders possess legitimate architectural authority, subordinates often comply without requesting validation. Threat actors leverage this dynamic to acquire privileged cloud infrastructure credentials. Legitimate compliance audits never request session tokens or plaintext secrets via email.
