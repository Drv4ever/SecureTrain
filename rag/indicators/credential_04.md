tactic: credential
title: Remote Work VPN and VDI Gateway Migration
source: CISA Advisory on Remote Access Exploitation
technique: Perimeter Gateway Harvesting
---
Targeting remote and hybrid employees, this attack claims that the corporate VPN gateway, Citrix portal, or remote desktop client has migrated to a new cluster. The email instructs employees to test their connectivity and update cached credentials on the linked web portal. Because remote workers depend on VPN connectivity for daily tasks, compliance is high. Employees should always launch VPN software directly from their operating system rather than following email hyperlinks.
